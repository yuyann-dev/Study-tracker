# Study Tracker · 智能学习追踪系统

一个纯前端的学习进度追踪工具，支持刷题打卡、艾宾浩斯间隔重复复习、错题本管理。所有数据存储在本地浏览器，无需联网、无需后端、隐私安全。

在线体验：**在这里填你的 GitHub Pages 链接**

---

## ✨ 功能特性

### 📚 三种任务类型

| 类型 | 说明 |
|---|---|
| ✏️ **刷题** | 按页码或按套卷追踪习题册/真题进度，支持板块权重计算 |
| 📖 **背书** | 基于间隔重复原理的艾宾浩斯复习，按掌握程度自动调整复习间隔 |
| 📝 **错题本** | 支持自由出处 / 习题册 / 套卷三种记录方式，自动安排错题复习 |

### 📊 进度追踪

- 实时进度显示（已完成/总量 + 百分比）
- 进度曲线图：实际进度 vs 理想进度对比
- 每日学习量自动计算
- 预计完成日期智能预测
- 历史打卡记录

### 🧠 间隔重复复习算法

- **经典间隔模式**：严格按间隔天数提醒复习
- **均匀分布模式**：自动将复习任务错峰到每天，避免单日复习量过大
- 掌握度五级评估：忘记 / 模糊 / 困难 / 良好 / 掌握
- 复习间隔可自定义

### 🗂️ 单元化管理

- 按章节/单元组织学习内容，最多支持 3 级嵌套（章 → 节 → 小节）
- 单元掌握度颜色标识，直观查看各模块掌握情况
- 薄弱点看板：自动统计各单元错题分布
- 单元模板：常用教材结构一键加载，支持保存自定义模板

### 💾 数据安全

- **三重本地存储**：localStorage + IndexedDB + Cache API 自动备份
- 数据损坏时自动从备份恢复
- 一键导出 / 导入 JSON 备份文件
- 无痕模式检测提醒
- 存储容量预估与低空间警告

### 📱 PWA 适配

- 移动端响应式设计
- iOS 添加到主屏幕后全屏运行
- 安全区（Safe Area）适配，不被刘海/底部指示条遮挡
- 深色 / 浅色 / 跟随系统三种主题

---

## 🛠️ 技术栈

- **原生 HTML / CSS / JavaScript**，单文件实现，零依赖
- **IndexedDB** 本地数据库快照备份
- **Canvas** 绘制进度曲线与统计图表
- **Cache API** 离线缓存
- **PWA** 移动端全屏体验
- 响应式布局，适配桌面端与移动端

## 🚀 使用方法

### 在线使用
直接访问上面的在线体验链接。

### 本地使用
下载 `index.html`，双击用浏览器打开即可。

### 移动端添加到主屏幕
1. 用 Safari / Chrome 打开页面
2. 点击浏览器「分享」按钮
3. 选择「添加到主屏幕」
4. 像原生 App 一样全屏使用
