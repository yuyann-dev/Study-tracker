## 研究背景与目标

传统学习追踪工具多停留在打卡与记录层面，缺乏对学习节奏的智能感知与自适应调整能力。本项目设计并实现了一个融合**大模型Agent、基于个人画像的个性化调度算法与多端同步架构**的全栈智能学习系统，能够根据用户学习行为动态调整任务安排，并通过AI助手提供基于真实数据的个性化学习建议。

系统已上线运行，支持PC/平板/手机多端访问，具备完整的用户认证、数据同步、AI交互与生产级部署能力。

## 核心技术亮点

### 大模型Agent系统

- **Function Calling工具调用框架**：10+个数据查询与操作工具，AI自主判断调用时机与参数
- **长期记忆机制**：自动提取用户学习习惯与偏好，持久化存储，后续对话自动加载，支撑个性化推理
- **智能任务时长预估**：AI根据今日任务清单+长期记忆预估每项任务总耗时，打卡后系统按比例计算已学时长，用户手动校准形成闭环
- **联网搜索能力**：集成搜索API，AI自主判断是否需要搜索，结果附参考文献

### 自适应排期算法

三大学习模块各有针对性的排期算法：

**刷题本 — 动态追赶与可行性预测**
- EWMA指数加权移动平均计算用户实际学习速率（半衰期14天，窗口28天）
- 四级可行性评估（ok/tight/stretch/impossible），提前预警
- 临考冲刺模式，支持战略放弃指定范围

**错题本 — 前紧后松自适应排期**
- 前紧后松预测：根据历史错题收录速率预测未来新增量，提前均摊
- 自动均衡摊派：超额条目自动摊到未来，逾期过久强制留当日
- 舒适量与智能容量：EWMA实际速率动态调整硬上限
- 主动提前复习：到期量不足时提前调度近期将到期的薄弱条目

**背书本 — 艾宾浩斯启发的双窗口调度**

传统艾宾浩斯遗忘曲线揭示了记忆随时间衰减的规律，复习间隔通常按1天、2天、4天、7天、15天固定递增。固定间隔的痛点在于：不考虑内容难度差异、用户实际掌握度以及考试截止日约束，容易出现单日复习量爆量而另一天无事可做的情况。本项目参考这一记忆规律设计复习调度，同时针对上述痛点做了创新：

- 新学窗口与复习窗口分离，保证考试前全部内容走完复习周期
- 均匀间隔模式，将待复习内容平摊到每日，避免固定间隔导致的单日爆量
- 保持期复习，间隔逐渐拉长（30→45→60天），用最少复习量维持记忆

### 间隔重复复习系统

- 基于掌握度的错题与背书内容复习间隔动态调整
- 错因标签权重计算，薄弱点优先调度
- 错题快录批量录入，自动关联对应刷题本
- 三态评价（做对/看答案/又错了）驱动掌握度更新

## 多端数据同步

采用「本地缓存 + 云端中枢」的最终一致性方案，云端作为多设备数据汇聚与冲突解决的核心：

1. 所有操作即时写入浏览器本地存储，离线可用
2. 登录后自动同步至云端，服务端按updatedAt时间戳执行LWW合并
3. 墓碑机制记录删除操作，防止已删数据在多端同步时复活
4. ETag增量同步，数据未变时返回304，节省流量
5. 本地存储三层备份（localStorage + IndexedDB + Cache API），自动降级恢复

## 功能模块

- **多项目管理**：刷题本（习题册/套卷模式）、错题本、背书本
- **今日总览**：学习状态感知、进度鼓励、任务清单
- **AI学习助手**：对话式交互 + 工具调用 + 长期记忆
- **错题管理**：错因标签、薄弱点看板、复习热力图
- **背书管理**：新学/复习双窗口、保持期复习
- **每周小结**：多维度统计 + 环比分析 + 个性化文案
- **自习室**：创建/加入、公开广场、成员隐私分层
- **管理员后台**：用户管理、数据统计、操作审计

## 快速开始

### 本地开发

```bash
# 后端
cd backend
npm install
node server.js

# 前端：直接用浏览器打开 frontend/index.html，或用任意静态服务器
```

### Docker部署

```bash
cp .env.example .env  # 填入配置
docker-compose up -d
```

## 后续规划

考研结束后计划将本项目继续完善作为毕业设计，主要方向：

- **前端可维护化**：从原生JS逐步迁移到组件化框架，提升可维护性和开发效率
- **后端数据库优化**：从SQLite迁移到PostgreSQL，支持更复杂查询和更高并发
- **高并发处理**：引入Redis缓存、消息队列，支持更大用户规模
- **测试体系**：完善单元测试、集成测试、E2E测试，提升代码质量
- **排期算法优化**：A/B测试与效果量化评估，持续优化算法参数
- **AI能力增强**：多轮对话优化、更细粒度用户画像、个性化报告生成
- **多模态输入**：拍照识题（图像识别）、PDF/Word文件上传解析，接入多模态大模型与OCR，丰富学习资料输入方式
- **社区化功能**：学习经验分享、题目讨论区
