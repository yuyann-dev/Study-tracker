# 用户模拟：背书 + 错题本混合用户（考研场景）

> 画像：考研党，同时使用背书模式（recite）和错题本模式（mistake），两个项目之间有联动诉求。
> 模拟依据：《背书模式逻辑盘查.md》——背书复用错题本三态间隔内核，但外围调度层半套、策略条对背书是死代码、过期横幅/设置页残留"错题本"文案、无跨项目关联字段、录入不错峰堆同一天。
> 视角：只站在"背书 + 错题本混合用户"角度，不跨画像。

---

## 0. 我是谁

- 考研倒计时约 45–60 天，同时在跑两个背书项目（政治背诵、专业课名词解释）和两个错题项目（数学错题、英语阅读 / 政治真题错题）。
- 我的节奏：早上先清背书待复习（输出型，要张嘴背），下午 / 晚上清错题（做题型）。
- 我的核心焦虑：**"背了不等于会做"**——马原、专业课那些我背得滚瓜烂熟的点，一到真题应用题上还是错。我希望 app 能把"背"和"做题"串起来看，而不是两个互不相通的盒子。

---

## 1. 场景还原

### 场景 A：早间 dashboard 与双模式切换
早上 7:00 打开 app：
- 📖 背书分组：政治背诵（进度 62%，今日待复习 8 条，今日新学目标 3 页）、专业课名词解释（进度 41%，待复习 5 条）。
- 📝 错题分组：数学错题（待复习 12 道）、英语阅读错题（待复习 6 道）。

我先做政治。复习队列里三态按钮是「记得 / 模糊 / 忘记」，快捷键 1/2/3。做到"剩余价值的三个组成部分"，我卡了壳——按了 2（模糊）。这时候心里咯噔一下：这个点我上周在政治真题选择题里错过一次。但那条错题我是录在"专业课错题"项目里的（政治错题太少，我没单独建项目），现在我**没有任何入口**能跳过去看那条错题长什么样、当时错因是什么。只能凭印象继续背。

背完 8 条切到数学错题，三态按钮自动变成「做对了 / 看答案 / 又错了」——按钮文案跟着项目类型走，这点我很满意，不用重新认按钮；快捷键还是 1/2/3，肌肉记忆没断。

### 场景 B：周日晚上批量录入背诵
周日 21:00，我花 40 分钟把下周要新背的政治内容一次性录进去，共 10 条（按章节逐条加，填内容、填页码区间、三态选"模糊"——第一遍学完半懂不懂很正常）。

录完翻复习队列一看：**10 条全部排在明天（周一）**。周一早上待复习直接 8+10=18 条，按我背书一条要张嘴复述 2–3 分钟，根本背不完。

对比：我在数学错题本里新收错题时，系统会自动把复习日摊到未来几天（均匀错峰），不会让我某天突然面对一堆新错题。**同一个 app，错题本录入是"智能"的，背书录入是"裸奔"的。** 我只能等周一到期那天，指望系统自动帮我摊开——但周一早上的我已经被队列吓到了。

### 场景 C：考完后的过期横幅与设置页出戏
12 月 26 日（考研结束，deadline 已过），我打开政治背诵项目想做个收尾归档。顶部弹出过期横幅：

> "这本错题本陪你走过了备考的日子……"

我愣了三秒：**我这是错题本吗？** 我明明这两个月一直在用它背书。又点进设置页想调整一下间隔，复习模式那一栏下面赫然一个按钮——「💡错题本使用指南」。我点都不敢点，怕点进去给我讲"怎么归因错因"。

还有身后排队提示里一句"最近每天新收约 X 道……错题会越攒越多"——背书项目里显示"错题"两个字，很出戏。

### 场景 D："背毕业的点还是错"
专业课"纳什均衡"这个点：
- 背书项目里我背了 3 轮，最后一轮连续 good，弹了"确认掌握了吗"，确认后毕业，卡片上标记"已掌握 ✅"。
- 结果做 2024 年真题，考到这个概念的应用题，我又错了。我把这道题录进错题本，选了错因。

现在 app 里是两张互不知道的卡片：背书卡片说"已掌握"，错题卡片说"新收"。我对着两条记录发呆：**到底掌握没掌握？** 我的真实判断是"会背定义，但不会套到应用题上"——这恰恰是考研最致命的薄弱点。可 app 给不了我这个视角，它把"背"和"做题"切在了两个盒子里。

## 2. 逐条回答

### Q1：同时管理背书和错题本，两个模式的交互顺畅吗？

**半顺半卡。**
- 顺的部分：复习队列底层是同一套渲染（三态按钮、快捷键、错峰逻辑我两个项目都在用），切换项目时不需要重新学操作；仪表盘上背书和错题分组陈列，一眼能看到各自的今日量。
- 卡的部分：**两个项目之间没有任何桥**。场景 A 里"背到一半想起错过这道题"的瞬间，是我每天最常见的念头，但 app 给不了跳转。我现在的土办法是在背书条目的"备注"里手写"关联错题见数学项目第 N 条"——但这个备注不会在错题那边反向显示，等于单向便签，时间长了我自己都不看。

### Q2：背书的"掌握"和错题本的"攻克"在 UI 上区分清楚吗？

**三态按钮区分清楚，但毕业术语 / 边角文案串味。**
- 清楚的地方：复习队列里，背书项目三态是「记得 / 模糊 / 忘记」，错题项目是「做对了 / 看答案 / 又错了」——这个按类型切换我体验到了，翻项目时不会按错。
- 出戏的地方：共享渲染里的大文案还残留"错题腔"——过期横幅写"这本错题本陪你走过了备考的日子"，身后排队写"错题会越攒越多"。背书项目里出现"错题"二字，等于把"攻克"语境硬塞进了"掌握"语境。
- 我期待的口径：背书项目从头到尾用"条 / 掌握 / 背诵"，错题项目用"道 / 攻克 / 错题"。毕业确认弹窗我希望背书问"确认掌握了吗"、错题问"确认攻克了吗"——目前三态按钮分得开，但横幅类大文案没按类型分支干净。

### Q3：背书页面有没有"错题本使用指南"之类的错位文案？

**有，而且不止一处。**
- 设置页复习模式那一栏下面，有一个「💡错题本使用指南」按钮，**我的背书项目里也显示着**。点进去会看到给错题本写的指南（错因归因、怎么收录错题那一套），跟背书完全无关。
- 过期横幅："这本错题本陪你走过了备考的日子"——背书项目过期后显示这句，非常违和。
- 身后排队提示："最近每天新收约 X 道……错题会越攒越多"——背书应该说"条 / 背诵"。
- 我作为用户的判断：这些不是阻断性 bug，但每见一次我就更确信一件事——**背书模式是套在错题本引擎上的一层皮**，不是一个被认真设计过的模式。这种感受比功能缺失更伤信任。

### Q4：想把背书内容关联到错题本，系统有没有这个能力？

**没有。这是我作为混合用户最大的落空。**
- 我翻遍背书项目和错题项目，没有任何字段、按钮、入口能把一条背书条目和一条错题绑起来；项目层面也没有"背书项目 ↔ 错题项目"的关联设置。
- 背书条目里其实建了"错因标签"数组，但录入界面里这个下拉框被藏掉了——我连"这条我为什么忘"都打不了标。
- 我现在的土办法（场景 A / D 里说的）：在备注里手写关联。但备注是死文字，不会在错题那边反向提示，也不会在我复习时主动弹出来。
- 我真正想要的：见下面 Q8 的功能①。

### Q5：两个模式的设置项独立吗？会不会互相影响？

**数据层面独立，UI 层面混用。**
- 独立的部分：间隔表、复习模式（均匀 / 经典）、每日舒适量、每日容量都是项目级字段。我给政治背书设舒适量 6、错题设 10，互不干扰；甚至可以一个项目用均匀、一个用经典，没冲突。
- 混用出问题的部分：
  1. 设置页里「硬截止日」复选框在我的背书项目里也能勾，但勾了之后**背书排期几乎不变**——我一开始以为勾上"考试结束就停止排新复习"，结果什么都没发生，白勾。
  2. 「💡错题本使用指南」按钮塞在复习模式设置区里，背书项目可见——见 Q3。
- 结论：设置不会互相污染数据，但背书项目的设置页里混进了错题专属控件和帮助文档，我会误点、误勾。

### Q6：背书三态（记得 / 模糊 / 忘记）和错题三态一致吗？

**底层模型一致，按钮文案按类型切换，我接受这个设计。**
- 底层：两个模式共用同一套间隔规则——"记得"进下一轮、"模糊"也进轮但间隔被压、"忘记"回首间隔连续两次退一轮。翻项目时这套逻辑不用重学。
- 文案：背书是「记得 / 模糊 / 忘记」，错题是「做对了 / 看答案 / 又错了」——按项目类型切换，我体验到了。
- 语义上的微妙差别：背书的"模糊"= 能复述大概但不流畅；错题的"看答案"= 没做出来但看了答案懂了。两者都会压缩间隔，这个处理我觉得合理。
- 快捷键 1/2/3 在两个项目里都映射 good/fuzzy/forgot，肌肉记忆连续。
- 唯一希望微调：背书录入时第一遍学完三态默认是"记得 / 模糊 / 忘记"，我其实大部分时候选"模糊"——这个默认值 OK，不用改。

### Q7：我最痛的 3 个体验问题

**痛①：背书项目里到处是"错题腔"残留（信任问题）**
过期横幅"这本错题本陪你走过了备考的日子"、设置页"💡错题本使用指南"按钮、身后排队"错题会越攒越多"。我知道底层是复用错题引擎，但用户视角背书应该是一等公民。这些残留让我每次看到都出戏，久了我会怀疑"背书模式是不是没人维护了"。

**痛②：批量录入背诵全部堆到第二天（日常效率问题）**
周日晚上录 10 条政治背诵，全部排到周一；周一早 due 列表爆炸。错题本新收错题会自动错峰，背书却不会——同一个 app，两套待遇。我要么周末不敢批量录，要么周一早上被 18 条压垮。

**痛③：背书和错题完全割裂（核心诉求落空）**
我背了 5 轮毕业的考点依然在真题里错，系统没有任何线索告诉我"这个点你会背但不会用"。考研的核心矛盾就是"背了不会用"，app 却把"背"和"做题"放进两个互不相通的盒子。这是我作为混合用户最想要、却完全拿不到的东西。

### Q8：我最需要的 3 个功能

**功能①：知识点级双向关联（背书 ↔ 错题）**
- 一条背书条目可以手动绑定 0..N 道错题（或者按"知识点标签"自动汇聚）。
- 背书卡片复习时显示："关联错题 X 道，最近错于 10/2，错因：应用题型不熟"。
- 错题卡片复习时反向显示："该考点已背诵 3 轮，最近掌握状态 ✅ 已毕业 / ⚠️ 模糊"。
- 价值：我能一眼挑出"会背但不会做"的高频考点，优先补应用题训练——这直接对应考研提分点。

**功能②：背书临考策略入口（临考可调）**
- 距考试不足一个完整复习周期时，背书项目应该有策略条，至少支持：
  1. 暂停新页收录（临考只复习、不开新章）；
  2. 低频章节降频 / 后置（保高频章，低频章往后排）；
  3. 战略性放弃某些低性价比章节。
- 我感觉系统底层其实已经有"低频降频"的排期逻辑，但我在背书项目里**根本找不到开关**。错题本临考时会弹策略条给我选，背书项目就光秃秃一片——临考我最需要决策辅助的时候，app 反而沉默了。

**功能③：背书录入即错峰 + 批量粘贴录入**
- 录入瞬间就按均匀模式把复习日摊到未来几天（跟错题本录入对齐），不要全堆第二天。
- 支持一次粘贴多行（每行一条背诵内容），自动拆成多条条目，页码区间可以批量设。
- 顺便：把已经建了但被藏掉的"错因 / 遗忘原因"标签还给我——让我标记"概念混淆 / 定义遗漏 / 记混页码"，一周后我能统计自己最常忘在哪类原因上。这个字段系统里其实已经有了，只是 UI 没放出来。

---

## 3. 一句话总结

作为一个同时背政治、刷数学题的考研党，我对 app 的期待不是"两个独立模式"，而是**一条从"背诵"到"做题"的完整闭环**。现在背书模式借了错题本的引擎跑起来了，但文案上还留着错题本的胎记、录入上没有错题本的智能、内容上又和错题本完全不通——我希望下一轮迭代，背书能从"错题本的换皮"变成"和错题本平等、且能握手"的一等模式。
