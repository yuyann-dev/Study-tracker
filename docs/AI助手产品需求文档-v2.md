## v2 修订说明（从 v1 → v2 改了什么）

本轮修订来自 4 份用户代理评审（错题本 10 人 6.5、刷题本 10 人 6.5、背书本 10 人 6.5、混合场景 5 人 5.5）。**v1 的架构决策（本地优先、op 级撤销、用户自供 Key、AI 模块独立、克制 UI）全部保留**，本轮只动"场景深度"。主要变更：

### A. 错题诊断（§11.1 重写）
1. **聚类去数学偏科**：从"只认 units 章节树+页码"扩展为**三维聚类**——① 章节树（数学/专业课）② 题型/考点标签（英语细节/推断题、政治考点号）③ 语义关键词（文科名词、跨章节重复考点）。没有页码的项目也能用。
2. **诊断必带"最小下一步 + 时间预算"**：允许用户输入"今天只有 X 分钟"，AI 从薄弱点里切出"今天先做这 3 道"，其余折叠为"暂存"（错题洪水开关）。
3. **三类行为诊断纯本地戳破**：伪掌握（`manualMastered=true` 但 reviews 仍忘）、跨年顽固（`learnedDate` 跨年仍错）、只记不练/过度整理（错题只增无 review、note 很长但二刷正确率低）。
4. **粗标签二次细分**："粗心"占比超阈值时，对这批题的 note 做二次聚类（正负号/进位/漏条件），并给流程矫正类 action（做题检查清单）。
5. **note 抽样回注**：不再一刀切砍掉 note，对长 note 高价值错题抽样读入做错因归纳。

### B. 刷题（§11.6 + 数据模型 + actions）
1. **补套卷数据模型**：套卷 records 增加 `score` 与按 section 的 `{score, fullScore, timeSpentMin}`；新增 `/api/ai/paper-trend` 本地趋势接口。
2. **actions 白名单从"调参数"升级为"改策略"**：新增 `mark_units_optional`（砍范围）、`create_mock_paper_project`（外部资料建空项目）、`compare_plans`（三方案对比卡）。
3. **主动触达扩到隐性问题**：新增"错题本连续 7 天无 review""稳定低产出（连续 14 天低产出但天天打卡）""双刷题项目并行且都未达标"三条触发。
4. **阶段切换双向化、阈值可调**：支持"已切套卷但章节未完"的并行过渡诊断；阈值随用户目标分数档位（冲分/稳分/过线）动态定；建套卷项目前先查重避免重复创建。
5. **冲刺触发提前到 60 天**，且**背书停新 ≠ 刷题停新**（冲刺期刷题反而要加新模拟卷）。

### C. 背书（§11.4 重写 + 易混点升 P1）
1. **按内容形态自适应出题**：名词→挖空；政治大题/论述→采分点/关键词骨架抽问+串段；英语作文→换题仿写+逐句批改；数学公式→双向卡+适用条件陷阱题。
2. **主动回忆升级为默认流程**：打开复习即遮罩答案（不再藏在"让 AI 考我"按钮里）；点"记得"前强制默写 1–2 个关键词防自欺；点"模糊"可勾选"忘了哪个点"，SRS 只对该点缩短间隔。
3. **积压减负 action**：新增 `defer_low_risk_items`（顺延低风险条目）、`compress_intervals`（考前压缩间隔）。
4. **易混点对比升 P1 并主动化**：基于"连续标模糊+内容相似"自动识别易混对，主动推对比表+一句话口诀，成对绑定排期。

### D. 混合/全局调度（v1 最大短板，补为 P0）
1. **全局时间守恒调度（§11.2 重写为 P0）**：用户输入每日可用时长 → AI 在该硬约束下做"此消彼长"的全局再分配，而不是逐科给建议。
2. **单位统一折算分钟**：从历史 records 推断每项目"页均/条均/套均耗时"，所有建议折算成"约 X 分钟"。
3. **跨科目 ROI 优先级排序**：多科同时落后时给"今天先救谁"的 P0/P1/P2 排序，而非并列三张红牌。
4. **科目级热力图（§11.7 新增）**：同科目下 exercise+recite+mistake 三项目按章节对齐，输出"刷题进度/错题密度/背书掌握率"三层热力图。
5. **偏科补救分阶段计划（§11.8 新增）**：4–8 周分阶段时间表，每周复盘自动调，附可持续性预览。
6. **周计划补位（F5.5）**：补上"今日计划"和"冲刺计划"之间的周级目标。
7. **冲刺减法清单**：已掌握条目自动降频，告诉用户"今天可以不做什么"。

### E. 数据/接口/路线图
- §5 新增表与字段、§6 新增接口、§9.1 扩 actions 白名单、§13 路线图按新功能重排 M1–M4。
- 文末附**四模块自评分**（错题 8.5 / 刷题 8.5 / 背书 8.5 / 混合 8.0）。

## 0. 阅读前必须知道的系统事实（源码走查结论，v1 已核实，v2 增补）

> 完整事实见 v1 §0，此处只列 v2 新增/被评审点名的部分。

1. **本地优先 + LWW 合并**：store 在 localStorage，后端 `user_data.store_json` 是副本；AI 改动必须走客户端 ops 补丁，**服务端绝不直接改写 store_json**（v1 已定，v2 延续）。
2. **项目字段（v2 新增可选字段，均幂等补默认）**：
   - `subjectKey`：科目归类（`math/english/politics/major1/major2`），用于跨项目聚合。
   - `minutesPerUnit`：推断的"每单位（页/条/套）预计分钟数"，由历史 records 时间差估算、用户可改。
   - `targetScoreTier`：`high`（冲高分）/`stable`（稳分）/`pass`（过线），动态决定阶段切换阈值。
   - 套卷 `records[]` 增加 `score`（总分）、`sections:[{name, score, fullScore, timeSpentMin}]`（逐 section 得分与用时）。
   - 错题 item 增加 `questionType`（题型，非页码聚类用）、`examYear`（考期/年份，跨年顽固用）。
   - 背书 item 增加 `form`（`essay|composition|term|formula|discuss|qa`）、`points[]`（采分点骨架）、`confusableWith[]`（易混对）、`deferredTo`（顺延日期）。
3. **排期算法**：`intervals=[1,2,4,7,15,30]`，周期和 59 天；背书新学窗口 = `deadline-59`；`weakThreshold=0.4`、`lapseRollback=2`。
4. **基建**：JWT `authRequired`、`ok/fail` 统一响应、`ensureColumn()` 幂等迁移、Node18 原生 fetch、单用户 store 5MB 配额。

## 1. 产品概述

### 1.1 一句话定位
**Study Tracker AI 助手是一个"握着你真实学习后台、还知道你今天只有几小时"的考研私教：它读你的刷题/错题/背书数据，在你的时间预算内告诉今天先救哪科、先做哪 3 道，并一键把计划改进系统——不是陪聊，不是给通用建议。**

### 1.2 v2 强化的价值主张（回应混合场景 5.5 分）
v1 已做到"知道你哪弱"，v2 补上"**在有限时间内，今天先救谁、砍什么、怎么取舍**"——从"单科进度报告器"升级为"全局时间调度教练"。

### 1.3 设计原则（v2 新增两条）
1–5 同 v1（主动/数据真改/省钱/用户持有/老用户零伤害）。
6. **时间约束优先**：任何规划建议都必须先知道"今天有多少分钟"，在硬约束下取舍，而非无限量加任务。
7. **减法比加法值钱**：尤其冲刺期，AI 要敢说"这些可以不做"。

## 4. 用户画像自动构建（v2 增补维度）

在 v1 §4.3 字段基础上，新增：

```json
{
  "habit": {
    "dailyAvailableMin": 300,          // 每日可用学习分钟（可由用户在 F1.7 输入覆盖）
    "peakTime": "晚间",
    "minutesPerUnit": { "math_1000": 6, "politics_recite": 3 },  // 各项目页均/条均分钟（自动推断）
    "weekendDrop": true
  },
  "targetScoreTier": "stable",          // high/stable/pass
  "subjects": ["数学三", "英语一", "政治", "专业课"],
  "_v2": true
}
```

**时间画像推断逻辑（纯本地）**：
- `dailyAvailableMin`：优先取用户 F1.7 最近一次输入；其次从近 14 天 records 的打卡时段跨度估算；无数据则默认 240 分钟。
- `minutesPerUnit`：若 records 有时间戳差（同一项目连续两条的时间间隔），用"产出量/时间差"滑动平均估算；无时间戳则给经验默认（数学页 6–8min、英语套 180min、政治条 3min），用户可改。

## 7. AI 数据读取与聚合策略（v2 增补）

### 7.1 漏斗不变
意图 → 取数清单 → 聚合摘要 → 小 JSON。绝不丢全量 store。

### 7.2 v2 新增聚合器（`aiDataAggregator.js` 扩展）
1. **三维错题聚类**：
   - 有 units 页码 → 章节树口径（数学）；
   - 无页码但有 `questionType` → 题型×错法矩阵（英语）；
   - 都没有 → 按 content/note 关键词轻量聚类（文科），**note 抽样**：只对 `errTag∈{概念不清,思路错误}` 且 note 长的条目读 note（≤20 条），其余仍截 40 字，平衡 token。
2. **科目级聚合**：按 `subjectKey` 把同科 exercise+recite+mistake 按章节树对齐，算热力图三指标。
3. **时间成本换算**：所有"建议日量"统一乘 `minutesPerUnit` 得分钟，action 标签显示"约 X 分钟"。
4. **行为诊断（纯本地零 token）**：
   - 伪掌握：`manualMastered=true` 且后续 reviews 仍出现 result=忘记；
   - 跨年顽固：`learnedDate` 跨年且同簇仍在错；
   - 只记不练：mistake 项目 records/items 增长但 reviews=0 持续 N 天；
   - 过度整理：note 长度分位很高但二刷正确率低。

### 7.3 Token 预算
同 v1（上下文截断、摘要缓存、预算硬顶）；v2 冲刺模式允许用户确认后预算翻倍（§10.4）。

## 11. 考研深度功能详细设计（v2 重写/扩充）

### 11.1 错题诊断（三维聚类 + 时间切片 + 行为戳破）

**输入数据**：mistake 项目 items（errTags、wrongStreak、reviews、page/setNo、questionType、examYear、note），同科目 exercise 进度（判断"没学过 vs 学了不会"）。

**算法（纯本地）**：
1. **归类口径三选一**（项目无 units 页码时自动降级）：
   - 章节口径：页码/题号段 → units 叶子章；
   - 题型口径：`questionType`（细节/推断/主旨…）× 错法二维矩阵；
   - 语义口径：content/note 关键词轻量聚类（同考点换皮题合并成"考点簇"）。
2. **每簇排序**：综合 wrongStreak、复习仍忘率、examYear 是否跨年仍错、是否"没学过被误判薄弱"（交叉 exercise 进度，未学完的章标灰，提示"先补基础"而非二刷）。
3. **粗标签细分**：某 errTag（如"粗心"）占比 >40% 时，对该批 note 二次聚类（正负号/进位/漏条件）。
4. **行为诊断**：并行算出伪掌握清单、跨年顽固榜、只记不练、过度整理四类。

**输出（强制带时间预算）**：
```
你数学 200+ 道错题，今天只给了自己 2 小时 →
【今天只做这 4 道】约 50 分钟：中值定理 wrongStreak 最高的 4 道（其余 196 道已折叠，别碰）
【戳破一个假象】你标了 mastered 的 3 条，近 3 次复习其实忘了 2 次（伪掌握）
【跨年病灶】"中值定理"2026/2027 各错 5 次——头号病灶
【粗心拆解】你的粗心里 60% 是正负号 → 建议建"做完圈正负号"检查清单
```
附带 actions：`create_review_list`（仅含选中簇）、流程矫正检查清单、伪掌握条目回流 `add_recite_items`。

### 11.2 全局时间守恒调度（v2 新增 P0，混合场景核心）

**痛点**：AI 逐科给建议，加起来远超用户今天能学的时间；多科都落后时不知道先救谁。

**算法**：
1. **输入**：用户今日可用预算 `budgetMin`（F1.7 chips 或画像 `dailyAvailableMin`）。
2. **单位统一**：每科建议日量 × `minutesPerUnit` → 折算分钟。
3. **ROI 打分**（每科/每项目 0–10）：
   - 落后幅度（gap）、科目分值权重（数学 150 > 英语/政治 100）、补救边际收益（刚启动/掌握率低的边际收益高）、距 deadline 紧迫度。
4. **时间守恒分配**：在 `budgetMin` 硬约束下做此消彼长——超前科降速让渡、落后科加时、未启动科冷启动，**总和 = budgetMin**，不允许超额。
5. **认知交替**：按"刷题（高强度）/背书（记忆）/错题（复盘）"交替排时间块，而非整块堆一科。
6. **输出 P0/P1/P2**：今天必须做 / 尽量做 / 可缓，并说明排序理由。

**输出示例**（今天 300 分钟）：
```
今天 5 小时，按此消彼长分配：
P0（必做）数学 二刷中值定理 4 道 = 50min（ROI 9，跨年病灶）
P0（必做）政治马原复习 8 条 = 25min（刚启动，边际收益最高）
P1（尽量）英语阅读 2 篇 = 40min
P1（尽量）专业课背书新内容 1 节 = 60min
P2（可缓）数学 1000 题新章 = 今天先不推进，维持手感即可
—— 英语已超前，从 2h 降到 40min，省出的时间给数学和政治。
```
附带一组 `adjust_daily_capacity`（有升有降）+ `compare_plans`（若用户想换方案）。

### 11.3 冲刺计划（60/30/7/1 天 + 减法 + 节奏）

- **触发提前到 daysToExam≤60**（v1 是 30，错过定调窗口）。
- **背书停新 ≠ 刷题停新**：背书项目执行"停普通新学"（肖四/时政破例挤时间）；刷题项目执行"换模拟卷"（1000 题剩余可放弃，转李林 6+4）。
- **减法清单**：每天筛出"已掌握且连续 3 次记得"的条目，自动 `lower_mastered_freq` 降为低频，明确告诉用户"这些今天可以不做"。
- **节奏型排期**：数学按"一三五套卷/二四六复盘/周日模考"，政治"每天 2 大题+50 选择"，专业课"每天回顾 1 章+周末默写"。
- 30/7/1 天粒度细化同 v1（作息对齐考试时间、考前 1 天检查清单）。

### 11.4 背书自适应出题 + 默认遮罩回忆

**默认交互升级**：打开背书复习列表**即遮罩答案**，先回忆再核对（不再是藏在菜单里的按钮）；点"记得"前强制在输入框敲 1–2 个关键词防自欺；点"模糊"可勾选"忘了哪个点"，SRS 只对该点缩短间隔。

**按 `item.form` 自适应出题**：
| form | 出题形态 |
|---|---|
| `term`（名词解释） | 挖空自测：把答案关键词挖掉让填，最快 |
| `essay`（政治大题/论述） | 自动切采分点，抽点默背→串段成 300 字，点模糊勾"忘了原理段还是材料段" |
| `composition`（英语作文） | 出新题让用户套模板仿写，AI 逐句对照原文批改模板是否套对 |
| `formula`（公式） | 双向卡（给公式默写条件 / 给场景选公式）+ 适用条件陷阱判断题 |
| `discuss`（简答论述） | 抽关键词骨架→让用户扩写成段→对照原文 |

**易混点（F4.3 升 P1）**：基于"连续标模糊 + 内容相似"自动识别易混对，主动推对比表 + 一句话口诀（"就差这一个点：____"），并成对绑定排期（复习 A 自动弹 B）。

**积压减负（F4.6）**：今日到期量 > 每日可复习上限时，`defer_low_risk_items` 把低危顺延 1–2 天、逾期折叠不堆红，首页只显示"今天先清这 8 条约 20 分钟"。

### 11.5 主动触达与心态干预（触发规则扩充）

本地零 token 巡检（每天打开 App 跑一次），触发信号在 v1（断签/严重落后/积压增长）基础上**新增**：
1. **错题本连续 7 天无 review**（只刷新题不总结型）；
2. **稳定低产出**：连续 14 天每日产出低于阈值但天天打卡（不催加速，而是"按你实际节奏重排/砍范围"）；
3. **双刷题项目并行且任一完成率 <80%**（章节+套卷都在刷但都不深入 → 给并行过渡方案）；
4. **待复习逾期数 > 阈值**（针对"打卡了但清不完积压"，而非只盯断签）。

话术原则沿用 v1：不说鸡汤，给"最小第一步 + 预计分钟"，必要时 `adjust_daily_capacity` 临时降到轻松完成的量。

### 11.6 阶段切换（双向 + 阈值可调 + 查重）

- **阈值随 `targetScoreTier`**：冲高分 80%/60%、稳分 70%/50%、过线 60%/40%。
- **双向过渡**：不仅"章节→套卷"，也处理"已切套卷但章节未完"——给"章节降频维持手感、主力转套卷、套卷错题反哺补漏"的过渡方案。
- **建项目前查重**：已有 set 模式项目就不再 `create_mock_paper_project`，改为优化现有节奏。
- **store 外资料建议**：可给文字建议（"1000 题剩余建议放弃，转李林 6+4"），并附 `create_mock_paper_project` action。

### 11.7 科目级热力图（同科目多模块打通，v2 新增）

按 `subjectKey` 把同科 exercise + recite + mistake 按章节树对齐，每叶子章输出三指标：刷题完成率 / 错题密度 / 背书掌握率。纯本地算，一张图指出"第 5 章是重灾区：刷题错 8 道、背书掌握率仅 20%、错题本高危 6 道出自这里"。今日计划里提示"同一知识点的 3 条背书 + 2 道错题建议一起复习"，避免一天复习两遍。

### 11.8 偏科补救分阶段计划（v2 新增）

对严重偏科用户，生成 4–8 周分阶段时间表（落 `ai_plan_records(kind=remediation)`）：每周一调各科日量、每周日复盘进度动态修正。**附可持续性预览**："按此节奏数学 4 周追到 70%，但专业课可能从正常滑到落后 10%，接受吗？"——让用户在应用前看到代价。超前科目不只降速，还检查其薄弱子模块做"科目内再平衡"。
